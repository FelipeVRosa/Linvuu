# Vuu 2D para o site — 29/10/2026

Felipe aprovou a imagem de referência do Vuu sorridente e pediu uma versão 2D para o site, com integração no GitHub e Render. Esta decisão atual substitui as instruções antigas que classificavam a integração visual como futura.

**Status: concluído para o site.** PR #395 integrado no commit `ba7a76bed9b898e5dd7ec346794955c430e6b0e7`; CI, Lighthouse, revisão visual e prévia Android passaram, o Render publicou esse commit e a home foi conferida em produção. Em 29/10 o SVG público respondeu HTTP 200. O usuário confirmou a conclusão da entrega web. Este status não inclui o APK nem uma biblioteca de animações.

O arquivo `public/assets/vuu/vuu-feliz-2d.svg` é uma interpretação vetorial desenhada a partir da referência aprovada e de um estudo 2D gerado para esta tarefa. Mantém duas faixas verdes e o rosto claro, com sorriso e bochechas discretas; não é uma vetorização geométrica exata da imagem tridimensional. O SVG anterior permanece no repositório. A home usa a versão nova no cartão de áudio e na apresentação do Vuu, como imagem decorativa ao lado do texto. Não há animação nem informação apresentada exclusivamente pela imagem.

Limites: não altera o APK, não cria promessa pedagógica, não estabelece uma biblioteca completa de expressões ou animações e não substitui testes com pessoas. Se precisar reverter a integração, restaurar as referências a `vuu-neutro.svg` em `src/pages/HomeBrasileiros.tsx`.
