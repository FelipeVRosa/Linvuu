## Depois da habilitação
1. Confirmar acesso API e criar bucket Standard somente para piloto público, inicialmente sem expor domínio ou r2.dev.
2. Copiar os 20 arquivos, preservando origem e metadados de integridade. Recusar sobrescrita se existir objeto de mesmo nome com hash diferente.
3. Conferir tamanho e hash após upload. A presença do objeto não comprova acesso correto pelo navegador.
4. Configurar CORS GET/HEAD para origens web e Capacitor efetivamente usadas. Validar AllowedOrigins, AllowedHeaders e ExposeHeaders contra o esquema da API antes de aplicar.
5. Testar entrega pública de piloto com domínio/endpoint de teste apropriado, incluindo Range/206, MIME audio/mpeg, HEAD, origem web e https://localhost.
6. Só então propor integração de uma unidade na aplicação. Sem trocar URLs globais, apagar origem ou mexer em conteúdo privado nesta fase.
