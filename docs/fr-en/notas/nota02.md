## Adaptacoes (um item por padrao)
- "Passo N" virou "STEP N".
- il y a: comparado com "there is / there are" (que varia com o numero, ao contrario do frances).
- Contracao de preposicoes (du, des): comparado com "next to / in front of" do ingles, que nao se contraem.
- Demonstrativos: "este/esse/aquele" -> "this/that/these/those" (frances tem uma serie so + -ci/-la).
- Partitivo: "como pao / bebo agua" -> "I eat bread / I drink water" (ingles tambem omite o artigo; frances exige).
- Quantidade + de: "um quilo de macas" -> "a kilo of apples" (mesma estrutura).
- prendre: "vou tomar um cafe" -> "I'll have a coffee"; "conta/bom apetite" -> "the bill / enjoy your meal".
- Transportes en/a: comparado com "by train / on foot".
- Futuro proximo: "ir + infinitivo" -> "going to + verb"; removida a frase "facil para brasileiro".
- Imperativo: comparado com o imperativo ingles (verbo simples, sem pronome).
- Verbos pronominais: ingles quase nao usa reflexivo ("I get up"); o frances exige o pronome.
- ne... jamais: comparado com "never / not... ever".
- Verbos em -ir: "-iss-" no plural; pronuncia "fini-so" virou respelling "fee-NEE / fee-nee-SOHN".
- Adjetivos: ingles poe o adjetivo antes; o frances depois, salvo os BAGS (a sigla BAGS funciona em ingles: Beauty, Age, Goodness, Size, antes era Beleza/Idade/Bondade/Tamanho).
- Descricao fisica: "she has blue eyes" vs "elle a les yeux bleus".
- Centenas: "duzentos/trezentos" -> "two hundred / three hundred"; mantida a regra do "s" de cents.
- Pronomes tonicos: comparados com "me/him/them" depois de preposicao.
- Pronomes objeto: ingles poe o pronome depois do verbo ("I see him"), frances antes.
- "je trouve que / je pense que": ingles pode omitir "that"; frances nao.
- y e en: "vou la" -> "I'm going there"; "quero / quero disso" -> "I want some / I have two".
- Passe compose: "comi / falei" -> "I ate / I spoke"; negacao com "did" no ingles; "ha dois dias" -> "two days ago".
- Auxiliar avoir/etre: ingles usa sempre "have"; "levantei" -> "I got up".
- Mnemonico dos verbos de movimento traduzido para o ingles (go/come, up/down, enter/leave...).
- Gloss "demais" -> "too much"; "muito" (plusieurs) -> "a lot"; "pt" nao ocorreu como chave neste lote.
